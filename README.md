# Halo Auto Triage presentation

The interactive presentation is in [`index.html`](index.html). A print-ready, expanded handout is available as [`auto-triage-deck.pdf`](auto-triage-deck.pdf); it gives each clickable tab panel its own page so the complete presentation can be read without interaction.

Regenerate the PDF after editing the HTML:

```bash
python tools/export_pdf.py
```

The exporter uses only the Python standard library and writes a self-contained landscape PDF.
